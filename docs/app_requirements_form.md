# アプリ要件の質問票

## この質問票について

- 基盤システム設計のため、各アプリの要件を集めています。1部ずつ回答してください。
- まだ決まっていない項目は「未定」と書き、見込みがあればあわせて書いてください。
- いくつかの質問では、機能の必要度を次の3つから選択してください。

| 必要度 | 意味 |
|---|---|
| 必須 | ないとアプリが成り立たない |
| あるとよい | なくても使えるが、あれば体験や研究がよくなる |
| 不要 | 使わない |

## 前提

- アプリは、展示用端末(Androidタブレット、Windows・MacのPC)のブラウザで動くWebアプリとして作ります。アプリのファイルは会場のMacから配信し、端末にはインストールしません。
- 参加者は受付で基本情報を入力してコードを受け取り、展示用端末でコードを入力してからアプリを使います。データは参加者ごとにMacへ保存できます。
- 端末で動かすには重い処理は、Mac上のPythonで実行できます。
- アプリの終了時に、基盤がアンケート(全アプリ共通の設問とアプリ固有の設問)を表示します。
