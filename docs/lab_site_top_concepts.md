- プロトタイプ: `lab-site/top-concepts/index.html`(ブラウザで直接開ける。外部依存は Google Fonts のみ)

## 1. 方針

- トップのヒーローは **パッと見て「いいな」と思えること** を最優先にする。アルゴリズムの説明や指標の表示は載せない
- 研究テーマ(グラフ理論・機械学習・ネットワーク)は、雰囲気として伝われば十分とする
- 光る線と点、奥行き、ゆっくり続く動きで見せる。クリックすると少し反応する程度の操作に留める
- `prefers-reduced-motion` のときは止まった1枚で表示する

## 2. 3案

| 案 | 元にしたテーマ | 見え方 | 印象 |
|---|---|---|---|
| A 光の枝 | グラフ理論 | 点のあいだを光が枝分かれしながら広がり、余韻を残して消える | 静かで知的 |
| B 流れる境界 | 機械学習 | 二色の境目と等高線が液体のようにうねり続ける | やわらかく有機的 |
| C 伝わる星座 | ネットワーク | 回転する立体のネットワークを色の信号が駆けめぐる | 華やかで奥行きがある |

裏では A は最短経路探索、B は小さなニューラルネットの学習、C はネットワーク上の伝播を実際に計算しているが、画面上では説明しない。

## 4. 実データをもとにした試作(2026-10-03 追加)

プロトタイプ: `lab-site/top-concepts/topologies.html`。C 案(立体で信号が伝わる)の見せ方をもとに、形を実データや実在のグラフで決めた。

| 案 | 形 | データ |
|---|---|---|
| C-1 航空路線 | 回る地球儀の上に、路線数の多い300空港と1,262路線(各空港につき航空会社の多い路線を5本まで)を大円の弧で描く | OpenFlights(ODbL、2014年時点)、Natural Earth(パブリックドメイン) |
| C-5 有名なグラフ | C60 フラーレン → トーラス → 6次元超立方体 → ジオデシック球 を16秒ごとに切り替え。信号は控えめ | 計算で生成 |
| NN ニューラルネット | 3Blue1Brown 風の見た目で、ページ内の計算を1手ずつ実行して見せる。演出(加速・減速、残光)は入れず、1手 = 1拍(0.08秒)で再生する | scikit-learn digits で実際に学習した重み(テスト正解率 97%) |

- NN の1手の内訳(実際の処理順)
  1. 8×8 の画像を行優先で一列に並べる(1行 = 1手)
  2. 入力を上から順に見て、0 でない入力 a[i] ごとに z[j] += a[i] × W[i][j] を全ニューロンへ一度に足す(1入力 = 1手)。各ニューロン下のゲージが途中の合計
  3. バイアスを足す → シグモイド(出力層はソフトマックス)で出力を決める(各1手)
  4. 3層ぶん繰り返し、0〜9 の確率を棒で示す
- データは `tools/build_data.py` で `data/*.js` に変換している(numpy と scikit-learn が必要)。元データの取得先はスクリプト冒頭に記載
- 不採用: A-2 東京の鉄道、A-5 ケーニヒスベルクの七つの橋
- 保留: A-1 大学周辺の道路網(場所が未定。OpenStreetMap からの取得が必要)

## 5. 決定: C-5 有名なグラフ(2026-10-03)

トップのヒーローは C-5 にする。比較用のタブや操作ボタンを外した単独版を `lab-site/hero/index.html` に置いた(外部依存は Google Fonts のみ)。

- 形: C60 フラーレン → トーラス → 6次元超立方体 → ジオデシック球 を16秒ごとに切り替える。右下に形の名前を小さく表示
- 動き: ゆっくり回転し、2.4秒ごとにどこかの頂点から色の信号が出て、辺を伝って枝分かれする
- 操作(2026-10-03 改訂)
  - ドラッグで回す。手を離すと慣性で少し回り、やがて自動回転に戻る。スマホは横になぞると回る(縦はページのスクロール)
  - ホバー: カーソルに一番近い頂点と、その隣の頂点・辺を照らす(マウスのみ)
  - クリック/タップ: その頂点から幅優先探索(BFS)を実際に実行し、探索木の辺を距離の順に伸ばす。1ホップ = 0.3秒、色は距離で変わる(青 → 緑 → 紫 → 赤 → 橙)
  - 触っている間と探索の波が出ている間は、形を切り替えない(最後の操作から4秒たつと再開)
- 動きを減らす設定: 信号が広がった状態の1枚で止める。ドラッグで向きを変えられ、クリックすると探索の結果(探索木)をまとめて表示する
- 調整用の値(回転の速さ、信号の間隔や数など)はファイル内の `CFG` にまとめた
- 比較用の試作(`lab-site/top-concepts/`)は記録として残す

## 6. クリックの処理と配色の比較(2026-10-06)

比較ページ: `lab-site/hero/variants.html`。採用版と同じヒーローの下に切り替えボタンを置き、組み合わせを試せるようにした(選択は端末に保存)。どの処理もクリックした頂点から実際に実行し、起きた順に再生する。

| 処理 | 見え方 |
|---|---|
| 幅優先探索(現行) | 近い順に1ホップずつ波のように広がり、全体を覆う木になる |
| 深さ優先探索 | 1本の線が行けるところまで伸び、行き止まりで戻って別の道へ進む |
| 最も遠い点への最短路 | 一番遠い点までの道を1本だけ引く。静かで線が少ない |
| 最小全域木(クラスカル法) | 短い辺から順に選び、あちこちの小さな木がつながって1本になる。クリックした場所には依存しない |
| ランダムウォーク | 光の点がでたらめに歩き、通った跡が少しずつ消える |
| 貪欲彩色 | 近い順に、隣と違う色で頂点を塗る。C60 とトーラスは3色、超立方体は2色で塗り分けられる |

| 配色 | 中身 |
|---|---|
| 5色(現行) | 青・橙・緑・赤・紫。華やかだが、意味のない色の違いが多い |
| 2色 | 常時の信号は青、クリックした処理は橙。色で「誰が起こしたか」が分かる |
| 1系統 | 青から白へのグラデーション。処理の進み具合を明るさで表す |
| 単色 | 青のみ。もっとも落ち着くが、彩色の処理は色の区別がつかない |
