推しは C、A と B は下の階層で使う

C は3つのテーマが1枚の画面に重なる唯一の案です。グラフ(構造)、ネットワーク(伝わる)、学習(推定する)が同じ動きの中で説明できます。A と B は研究テーマ紹介のセクションや各テーマのページで、それぞれの見出し背景として使うと役割が分かれます。

発展させるなら

  • C のネットワークを研究室の実データにする(論文の共著・引用ネットワーク、メンバーと研究テーマの二部グラフ)
  • スクロールに合わせて C → A → B と計算が切り替わり、各研究テーマの説明につながる
  • ライブキャプションを全ページ共通の意匠にする(「いま何を計算しているか」を必ず書く)

要件で決めること

  • 研究室名、キャッチコピー(いまの文言は仮)
  • 主な閲覧環境(スマホの比率)と、明暗どちらを基本にするか
  • トップの役割(ヒーローのみか、研究紹介まで担うか)
  • 実データを使うか、使うならデータの更新方法
